# Week 10 - Java Practice Problems

This folder contains the Java practice problems completed for Week 10.

## Class Problems

### 1. Bank Account Withdrawal
Demonstrates abstraction, inheritance, and withdrawal rules for savings and current accounts.

### 2. Campus Vehicle Pass
Demonstrates abstract classes, interfaces, inheritance, and charging-bay eligibility.

### 3. Student Club Registration
Demonstrates Set collections, duplicate prevention, and overriding `equals()` and `hashCode()`.

### 4. Class Marks Grid
Calculates student totals, subject averages, and identifies the topper.

### 5. Payroll Register
Demonstrates inheritance and polymorphism to calculate employee payments.
